# 🏏 Hand Cricket Game

A simple console-based Hand Cricket game developed using Python.

## 🎮 How the Game Works

- The player bats first.
- Choose a number between 1 and 6.
- The computer randomly chooses a number between 1 and 6.
- If both numbers are the same, the batsman is **OUT**.
- Otherwise, the chosen number is added to the score.
- After the player's innings, the computer tries to chase the target.
- The player with the higher score wins the match.

##  Technologies Used

- Python
- `random` module
- `sys` module
